# UI Experiments

Addon de Minecraft Bedrock (resource pack) para testar UI customizada — HUD e telas próprias usando o sistema de `ui_defs.json` / `hud_screen.json` do jogo.

## Estrutura

- `le_UE_rp/` — resource pack com as definições de UI (`hud_screen.json`, `ui_defs.json`, `global_variables.json`).

## Como usar

1. Copie a pasta `le_UE_rp` para a pasta `resource_packs` do Minecraft Bedrock.
2. Ative o pack em um mundo com "Experimentos" habilitados, se necessário.
